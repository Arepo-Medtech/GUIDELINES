# Owner decisions

Standing decisions that shape how guidelines in this repository are sourced and written. Newest first.

| Date | Decision |
|---|---|
| 2026-09-24 | **KL confirmed all 920 queued licensed-source doses against the subscription** (621 AMH doses, previously owner-accepted, and 299 eTG additions): `KL 2026-09-24` on every row of `docs/attestation-queue.md`. The 156 doses where eTG differs from AMH stay annotated on their pages (`docs/etg-crosscheck-2026-09-24.md`). |
| 2026-09-24 | **All 621 licensed-source (AMH) doses are owner-accepted, not individually checked** (`~ owner 2026-09-24` in `docs/attestation-queue.md`). Reported separately from ATTESTED; a dose becomes CONFIRMED only when a person reads it against the subscription and replaces the mark with initials and a date. See `docs/attestation-loop.md`. |
| 2026-09-24 | **Git history is left as is.** Earlier commits still hold verbatim RCH text; the repository is private and no current page reproduces it. |
| 2026-09-24 | **ASIEM (Australasian Society for Inborn Errors of Metabolism) sources are kept, paraphrased and hash-anchored**, on the same footing as RCH (personal, non-commercial use terms). |
| 2026-09-24 | **Table rows may be anchored.** Clean tables in PMC sources are appended to the source text by `scripts/pmc_text.py --append-tables`, one self-describing line per row, so doses and thresholds that live only in tables can be cited and re-checked. |
| 2026-09-24 | **RCH content is paraphrased and hash-anchored, never quoted** (RCH Terms clause 5.2, personal use only). See `docs/rch-permission-request.md`. |
| 2026-09-24 | **A guideline draws on every good source for the disease.** Nothing already on a page is thrown away when a source is added; where sources disagree, both views are shown. |
| 2026-09-23 | **AI-use clauses are recorded, not excluding.** A publisher's AI or text-mining clause is copied verbatim into the method; only a paywall, login, archived/rescinded status or a bot challenge makes a source unusable. |
| 2026-09-23 | **International guidelines are acceptable first-line sources** (Australian practice largely follows UK/US/EU), with a banner and the PBS listing shown alongside. |
